# Prompt Master iPhone Skill

Accès complet à Prompt Master sur iPhone via Claude.ai sans CLI.

## Qu'est-ce que c'est ?

**Prompt Master** est un outil pour générer, affiner et structurer des prompts pour l'IA. Cette skill le rend accessible directement sur iPhone via Claude.ai.

Repo officiel : https://github.com/nidhinjs/prompt-master

## Utilisation rapide

```
1. Safari → télécharger ZIP de Prompt Master
2. Claude.ai → Upload la skill
3. /prompt-master ou langage naturel
4. Profit
```

## Cas d'usage

- Générer des system prompts
- Affiner des prompts existants
- Créer des templates de prompts
- Structurer des demandes complexes
