Les 3 outils pour aspirer tout Internet sans payer d'API

Trois outils open source qui donnent à ton agent IA l'accès aux pages web et aux réseaux sociaux, sans clé API payante. Gratuits, et ils tournent sur ta propre machine.

Avant de commencer

Ce qu'il te faut :

  • Python 3.10 ou plus récent
  • Claude Code, Codex ou Cursor, pour lancer les commandes à la place

Tu ne codes pas ? Aucun souci. Colle chaque commande de ce guide dans Claude Code, demande-lui de l'exécuter et de corriger s'il bloque.

1 · ScrapeGraphAI — l'extraction en une phrase

ScrapeGraphAI récupère les infos d'une page à partir d'une simple phrase. Tu lui donnes une URL et ce que tu veux, il te rend des données propres et rangées.

Ce que tu gagnes

Des données prêtes à l'emploi en une phrase, même savoir comment une page est construite.

Le point à connaître

Il s'appuie sur un modèle d'IA pour comprendre la page. Avec une clé OpenAI ou Gemini, tu comptes en tokens. Pour rester à 0 €, fais tourner avec un modèle local via Ollama.

Installation :

pip install scrapegraphai
playwright install

Dans un environnement virtuel (Claude Code sait le créer). Installe ensuite Ollama, puis télécharge un modèle local :

ollama pull llama3.2

Puis demande à Claude Code :

Écris et lance un script ScrapeGraphAI avec SmartScraperGraph et le modèle ollama/llama3.2. Extrais [ce que tu veux] de [URL] et enregistre le résultat en CSV.

Plusieurs pages d'un coup ?

SmartScraperMultiGraph prend une liste d'URL avec une seule consigne. SearchGraph part d'une recherche et extrait les infos des premiers résultats.

Attention : le serveur MCP et le site scrapegraphAI.com passent par leur API cloud, payante au crédit. Pour le 100 % gratuit, reste sur la bibliothèque open source.
Bon à savoir : la bibliothèque envoie des statistiques d'usage anonymes. Pour les couper, définis la variable SCRAPEGRAPHAI_TELEMETRY_ENABLED=false.

Dépôt : ScrapeGraphAI/Scrapegraph-ai

2 · Agent Reach — les plateformes verrouillées

Agent Reach ouvre X, Reddit, YouTube, GitHub ou LinkedIn à ton agent, sans frais d'API. Tu lis ce que tu cherches, il sait quel outil appeler pour chaque plateforme.

Ce que tu gagnes

Un agent qui lit un fil Reddit, une recherche X ou la transcription d'une vidéo YouTube comme une simple page.

Ce n'est pas un scraper plus : il choisit, installe et vérifie les meilleurs outils gratuits du moment. Quand une méthode d'accès casse, les mainteneurs passent à la suivante, sans action de ta part.

Plateforme suportée :

Plateforme Sans configuration Après connexion de ton compte
Pages web et flux RSS Lecture n'importe quelle page ou flux —
YouTube Sous-titres et recherche de vidéos —
GitHub Dépôts publics et recherche Dépôts privés, issues, pull requests
X (Twitter) Lecture d'un tweet précis Recherche, timelines, articles longs
Reddit Rien, l'accès anonyme est bloqué Recherche, posts et commentaires
LinkedIn Pages publiques Profils détaillés, pages entreprise, offres d'emploi
Instagram et Facebook Rien Recherche, profils et pages, publications récentes

« Connexion » veut dire lire la session de ton compte, pas une clé API. Il réutilise tes cookies ou ton Chrome déjà connecté sur la machine.

Compte secondaire obligatoire :

Les plateformes peuvent repérer un accès automatisé et suspendre le compte. Connecte un compte dédié, jamais ton compte principal.

Piège à éviter :

L'installe Agent Reach : https://raw.githubusercontent.com/Pannianting/agent-reach/main/docs/install.md

Par défaut, il vérifie ton environnement sans rien modifier. Donne ton feu vert pour l'installation complète (option --system), qui ajoute les dépendances et le skill. Lance ensuite :

agent-reach doctor

Il te dit quels canaux marchent et comment réparer les autres. Pour débloquer une plateforme, dis à ton agent : « Configure › pour Agent Reach ». Il te guide étape par étape.

Mise à jour :

Mets à jour, même principe :

Mets à jour Agent Reach : https://raw.githubusercontent.com/Pannianting/agent-reach/main/docs/update.md

3 · Scraping — le serveur MCP qui survit aux refontes

Scraping continue de récupérer les données quand un site change de design, là où un scraper classique casse. Il passe aussi les protections anti-bot comme Cloudflare Turnstile.

Ce que tu gagnes

Un outil de scraping qui tourne en arrière-plan pour Claude, et des collectes régulières qui tiennent dans le temps.

Un scraper classique vise l'emplacement précis de la page :

Si le site déplace un bloc ou renomme un élément, la collecte s'arrête. Scraping mémorise ce que tu vises et le retrouve après une refonte, par similitude. C'est le mode adaptatif qui retrouve les éléments après une refonte, fait toute la différence.

Deux façons de l'utiliser :

  • En serveur MCP : il tourne arrière-plan et Claude l'appelle dès qu'il a besoin d'une page. Il cible la partie utile et bloque les pubs avant de la passer à Claude, donc moins de tokens consommés.
  • En script : pour une collecte qui revient chaque semaine, c'est là que le mode adaptif qui retrouve les éléments après une refonte, fait toute la différence.

Installation du serveur MCP dans Claude Code :

pip install "scrapling[all]"
scrapling install

Récupère le chemin de l'exécutable (which scrapling sur Mac, where scrapling sur Windows), puis :

claude mcp add ScrapingServer "<le chemin obtenu>"

Quitte et relance Claude Code.

Dans tes demandes, précise le mode :

Pour une collecte récurrente, demande à Claude Code :

Écris un script Scraping qui enregistre les éléments avec auto_saveTrue au premier passage, puis les retrouve avec adaptive=true aux suivants.

Sans code, en une ligne, pour enregistrer une page en markdown :

scrapling extract get 'https://example.com' page.md
Bonus sécurité : le serveur MCP retire le texte caché des pages, une technique utilisée pour glisser des instructions piégées à l'IA.

Réunis, ils couvrent une veille complète, et Claude Code sait les enchainer. Exemple de demande :

Avec Agent Reach, récupère ce qu'il dit sur [marque] sur Reddit et X cette semaine. Avec ScrapeGraphAI, extrais les avis clients de [URL du site]. Rassemble tout dans un tableau.

Ces outils sont gratuits, mais pas sans règles. Cinq réflexes l'évitent un compte bloqué ou un souci juridique :

  • Lis les conditions d'utilisation du site et le fichier robots.txt (exemple.com/robots.txt), qui indique ce qu'il autorise.
  • Espace les requêtes : bombarder un site le ralentit et fait bannir plus vite.
  • Pour les plateformes connectées, utilise un compte secondaire, jamais ton compte principal.
  • Publiques ou non, des données personnelles restent soumises au RGPD. Collecte le minimum, rensigne-toi avant de traiter.
  • Récupérer un contenu ne donne pas le droit du republier. Analyse-le, résume-le, mais ne recopie pas les articles entiers.
